# Why is kube-proxy Missing in KOPS Cluster ?
If kube-proxy is missing, it could mean

Kube-proxy is not deployed:

Kops might have been configured to use another networking solution (e.g., Cilium) that doesn't require kube-proxy.
Custom Networking (e.g., Cilium):

Cilium is a powerful alternative to kube-proxy and provides networking features like eBPF-based routing.
If Cilium is configured, kube-proxy might not be necessary.
